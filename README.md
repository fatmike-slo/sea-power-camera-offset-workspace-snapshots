# Camera Offset & Workspace Snapshots

A Sea Power mod that gives you more control over your screen. Keep the unit you're watching in view, move the tactical map with a click, and save the window layouts you like.

## What it does

- **Better camera framing:** Keep the selected unit visible even when the tactical map takes up part of the screen.
- **Eight quick map layouts:** Switch map and 3D view arrangements with one click.
- **Four custom workspaces:** Save and restore supported window arrangements, map and camera; optionally restore at mission start.
- **Adjustable interface:** Automatic high-DPI scaling and a manual **100–300%** slider for the main window and mini launcher.
- **Easy access:** `Camera + Workspace` button or `Ctrl + Shift + U` during a mission.

## Getting started

1. Subscribe to this mod and **Anchor Chain v1.2** on Steam Workshop.
2. Launch Sea Power, open the in-game Mod Manager and **check (enable)** this mod.
3. **Restart Sea Power** after subscribing or updating. Subscribing without enabling and restarting is not enough.

Some game windows, including Unit Status and Unit Reference, may not retain their positions when restoring a workspace. Some windows must be opened once before position restoration.
