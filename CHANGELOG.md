# Changelog

## v1.0.2 — 300% UI scaling

- Extended manual UI Size slider from 100–200% to 100–300% in 1% increments.
- Existing saved scaling preferences and automatic high-DPI scaling are unchanged.
- Main controls and compact launcher scale together; screen-fit limits remain active.
- No changes to camera offsets, quick map layouts, workspace snapshots, input shortcuts or plugin GUID.

## v1.0.1 — High-DPI UI scaling

- Added automatic UI scaling for high-resolution displays, including 4K.
- Added a continuous 100–200% slider, with persistent preferences.
- Scaled both main panel and compact launcher, including mouse interaction.

## v1.0.0 — Initial release

- Camera offset controls, eight quick map layouts and four workspaces.
