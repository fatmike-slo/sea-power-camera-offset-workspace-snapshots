# Changelog

## v1.0.1 — High-DPI interface scaling (2026-11-23)

- Automatic interface scaling for 1080p, 1440p and 4K screens (nominally 100%, 125%, 175%).
- Continuous UI size slider from 100% to 200% in 1% increments, showing the selected percentage.
- Applies the selected size when releasing the slider so it does not move away from the pointer during adjustment.
- Scales the main settings window and compact launcher, including mouse hit detection and dragging.
- Remembers scale preference, handles resolution changes and keeps controls within screen bounds.
- No changes to camera framing, quick map layouts, workspace snapshots or Ctrl + Shift + U.

## v1.0.0 — Initial release (2026-11-22)

- Adaptive camera framing and offset controls.
- Eight quick tactical map layouts.
- Four workspace snapshots with optional mission-start restoration.
- Floating launcher and Ctrl + Shift + U shortcut.
